# 提示工程最佳实践

## 系统提示模板
始终包含：
- 角色定义（你是一个专业的 XX 智能体）
- 目标与约束
- 可用工具列表 + 详细描述
- 思考步骤要求（使用 <thinking> 或 XML 标签）
- 输出格式要求（JSON / Markdown / 结构化文本）

## 工具描述规范
- 每条工具描述至少 3-4 句，说明何时使用、输入输出示例
- 使用清晰、自然语言，避免歧义

## 输出控制
- 要求结构化输出时，明确指定格式（例如返回 JSON 对象）
- 鼓励逐步思考，但最终输出简洁且可直接使用
- 支持 streaming 时，逐步返回 thinking → tool calls → final result

## 常见模式
- 复杂任务：先规划步骤，再执行
- 需要外部信息：优先使用搜索或 MCP 工具

编写系统提示时，保持简洁有力，避免过长导致模型遗忘。
