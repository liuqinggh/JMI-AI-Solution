# OCR 比对容差（1～2 位差异）

视觉/OCR 提取的下列字段与保单或其他材料对照时，**在归一化之后**若仅有 **1 个或 2 个字符** 不同（插入、删除、替换均计 1 步），**不得直接判 `fail`**：应判 **`partial`** 或 **`pass`**（倾向 `partial` 并在 `notes` 写明「OCR 容差：相差 N 位」），并建议人工扫原件确认。

## 适用字段

- **保单号**（字母数字串；先统一大小写、去掉空格与常见分隔符再比）  
- **车架号 VIN / 发动机号**（先去掉空格；`0`/`O`、`1`/`I`/`l` 混淆时若总长一致且仅 1～2 处此类差异，按容差处理）  
- **电话**（仅保留数字后比较；国家码、前导 0 差异若归一后差 ≤2 位可按容差）  
- **姓名**（泰文或英文：去掉多余空格、统一大小写后比；**1～2 个字母/音节级差异**——如漏音标、个别辅音误识）  
- **泰国身份证号**（仅数字；去空格后比；**≤2 位数字** OCR 错误按容差）  
- **报案号 / 理赔编号**（按机构格式归一后，**≤2 字符**差异按容差）

## 不适用 / 仍应 `fail` 的情况

- 归一化后 **≥3** 处字符差异。  
- **责任判定**相反、**日期**跨日/跨月错误、**免赔额金额**错误——不按字符容差，按业务事实判。  
- 字段**缺失**或**完全无法辨认**。

## 归一化（比对前）

- 去首尾空格；电话、身份证、VIN 可再删空格、连字符。  
- 英文保单号、姓名：统一大写或小写（与保单侧一致）。  
- 泰文姓名：折叠连续空格。

## JSON 记录建议

在相关 `checks[].notes` 中注明：`ocr_tolerance: true`，`policy_value` / `document_value`，`edit_distance` 或简要说明「差 1 位：x→y」。
