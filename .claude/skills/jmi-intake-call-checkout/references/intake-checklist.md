# Intake call checkout（电话报案核对项）

逐项含义与比对要点：

1. **保单号和有效性**  
   - 通话中口述/确认的保单号是否与保单文件一致。  
   - 「有效性」在材料侧只能做号码与保险期间逻辑核对；是否承保中、未欠费等须核心系统查询，结论中应标注 `system_verification_required`。

2. **姓名和联系电话一致性**  
   - 来电人姓名（泰/英）与保单被保险人是否一致或可合理解释（代理人报案需另案处理）。  
   - 联系电话与保单登记电话是否一致。

3. **车牌号和车型一致性**  
   - 车牌（含登记府/曼谷等）与保单是否一致；注意泰文字母 OCR/口误易混。  
   - 品牌型号（如 TOYOTA HILUX REVO）与保单是否一致。

4. **事故日期是否在保单有效期内**  
   - 将通话中事故日期（公历）与保单 `Policy Period` 起止比较；含边界日。

可选记录（非清单必填）：现住址与保单地址不一致时，记入 `observations_outside_checklist`，不替代四项结论。
