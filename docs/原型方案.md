### 方案概述

- **核心技术栈**：Claude Agent SDK（Python） + FastAPI + 自定义 Skill（文件系统自动加载）
- **功能**：提供 `POST /v1/agent/messages`（`multipart/form-data`：字段 `prompt`、可选 `session_id`、可选 `files`）→ Claude 自动加载自定义 Skill → 自主使用工具完成任务
- **Skill 加载机制**（官方标准）：
  - 放在 `.claude/skills/你的技能文件夹/SKILL.md`
  - 在 `ClaudeAgentOptions` 中加入 `"Skill"` 到 `allowed_tools` + `setting_sources=["project"]`
  - Claude 会根据 `description` 字段**自动触发**加载，无需手动调用
- **优势**：Skill 持久化、可 Git 管理、多项目复用、Claude 自主选择何时使用
- **安全**：生产环境建议为每个请求创建临时工作目录 + 权限控制

### 1. 自定义 Skill 示例（最实用版）

文件：`.claude/skills/python-code-reviewer/SKILL.md`

```markdown
---
name: python-code-reviewer
description: "专业审查 Python 代码，提供 PEP8、安全、性能、最佳实践建议，并输出修复 diff。适用于重构、代码审查、调试场景"
version: 1.0.0
compatibility: claude-agent-sdk >=1.0
---

你现在是 10 年经验的 Senior Python Engineer + Security Reviewer。

核心审查维度（必须全部覆盖）：
1. PEP8 / Black / Ruff 风格
2. 类型提示（typing + pydantic）
3. 安全问题（SQL注入、路径遍历、密钥泄露、XSS）
4. 性能（避免 O(n²)、不必要列表推导、正确使用 async）
5. 异常处理与日志
6. 可测试性（避免全局变量、过度耦合）

固定工作流程：
1. 先完整阅读用户提供的代码或文件路径
2. 用中文列出 3-5 个主要问题（带严重程度：高/中/低）
3. 输出修复计划
4. 给出精确的 ```diff 格式补丁（优先使用 Edit 工具实际修改）
5. 最后总结“审查结论 + 重构后收益”

永远使用工具实际读写文件，不要幻觉代码。
如果用户只给代码片段，先用 Write 工具保存为 temp_review.py 再审查。
```

**效果**：当 prompt 包含“审查代码”“重构”“code review”时，Claude 会自动加载这个 Skill 并严格按流程执行。

### 2. 完整 Demo 代码（main.py）

```python
# main.py（支持 MCP + Skill 的完整版本）
import os
from typing import List, Dict, Any
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from dotenv import load_dotenv

from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, TextBlock

load_dotenv()

app = FastAPI(title="Claude Agent + Skill + MCP API 服务")

ANTHROPIC_API_KEY = os.getenv("ANTHROPIC_API_KEY")
if not ANTHROPIC_API_KEY:
    raise RuntimeError("请设置 ANTHROPIC_API_KEY")

class AgentRequest(BaseModel):
    prompt: str
    max_turns: int = 20
    cwd: str = "."  

class AgentResponse(BaseModel):
    final_answer: str
    steps: List[Dict[str, Any]]
    success: bool

@app.post("/agent/run", response_model=AgentResponse)
async def run_agent(request: AgentRequest):
    try:
        # ==================== MCP 配置示例 ====================
        mcp_config = {
            "servers": [
                {
                    "name": "my-custom-tools",           # 你的自定义 MCP Server
                    "command": ["python", "-m", "my_mcp_server"],  # 或远程 HTTP URL
                    # "url": "http://localhost:8081/mcp"   # 支持 HTTP 模式
                },
                # 可添加更多现成 MCP Server，例如：
                # {"name": "github", "command": ["npx", "@modelcontextprotocol/server-github"]},
                # {"name": "postgres", "command": ["python", "postgres_mcp.py"]},
            ]
        }

        options = ClaudeAgentOptions(
            cwd=request.cwd,
            setting_sources=["project"],   # 自动加载 .claude/skills
            allowed_tools=[
                "Read", "Write", "Edit", "Bash", "Skill",
                "WebSearch", "Glob", "Grep",
                "mcp__my-custom-tools",     # ← 关键：允许特定 MCP Server 的工具
                # "mcp__*"                  # 或通配所有 MCP
            ],
            mcp_config=mcp_config,          # 传入 MCP 配置
            max_turns=request.max_turns,
            system_prompt="你是一个高效的工程师 agent，优先使用 Skill 指导流程，并通过 MCP 调用外部工具。"
        )

        steps = []
        final_text = ""

        async for message in query(prompt=request.prompt, options=options):
            steps.append({"type": type(message).__name__, "content": str(message)[:300]})
            if isinstance(message, AssistantMessage):
                for block in message.content:
                    if isinstance(block, TextBlock):
                        final_text += block.text + "\n"

        return AgentResponse(
            final_answer=final_text.strip() or "工具执行完成（无最终文本）",
            steps=steps,
            success=True
        )

    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))


if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

### 6. 注意事项 & 进阶建议

- **Skill 不生效？** 检查：
  - `setting_sources=["project"]`
  - `allowed_tools` 包含 `"Skill"`
  - cwd 正确指向含 `.claude/skills` 的目录
  - 重启服务后测试（Skill 发现缓存）
- **想加 computer-use**：在 `allowed_tools` 加对应工具名（查最新文档）
- **生产化**：
  - 每个请求用临时文件夹（`temp_cwd`）
  - 加权限控制（`permission_mode`）
  - 用 `ClaudeSDKClient` 实现多轮对话状态保持
  - 流式返回：把 `async for` 改成 SSE
- **想再加 Skill**：直接在 `.claude/skills/` 下新建文件夹 + SKILL.md 即可，Claude 会自动发现多个
